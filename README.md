# HTML & CSS Portfolio Site – IBM "Code the Future" Bootcamp

During my time on the **IBM Code the Future** bootcamp, I had the opportunity to explore front-end development by building a simple and responsive website using **HTML** and **CSS**.

## 🌟 About the Project
This repository showcases my first steps into web development, where I designed a multi-section personal portfolio-style site. The goal was to understand the structure of webpages, apply CSS styling, and build something visually clean and user-friendly.

## 🛠️ Technologies Used
- **HTML5** – for semantic structure and layout
- **CSS3** – for styling and layout responsiveness

## 📚 What I Learned
- How to structure HTML documents properly with semantic tags
- CSS styling fundamentals (selectors, colors, fonts, spacing)
- Box model and layout positioning (flexbox basics)
- The importance of clean, readable code

## 📸 Preview
You can view the project live by opening the `index.html` file in your browser.

## Why This Repo Matters
This project marked the beginning of my journey in tech. Although simple, it helped me build confidence in writing code and laid the foundation for further learning in web development and beyond.
